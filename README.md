# browser-screenshot

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Скилл для **Codex на Windows**: открывает сайты, читает страницы, ищет нужные материалы и сохраняет скриншоты в PNG. Обычная работа выполняется в фоне через Playwright; окно показывается, когда нужен ручной вход.

Автор: **nonsik**.

## Что умеет

- Открывать указанный сайт или сервис и переходить по ссылкам на странице.
- Читать страницы и искать материалы с помощью актуальных снимков структуры страницы (snapshot).
- Делать скриншот видимой области страницы или конкретного поста; полную страницу — по отдельному запросу.
- Сохранять PNG с уникальным именем в `outputs/` текущей задачи и прикладывать изображение в ответ Codex.
- Повторно использовать входы, сохранённые в отдельном постоянном профиле Playwright.

По умолчанию скилл только читает сайт. Публикации, лайки, подписки, сообщения и другие действия от имени пользователя требуют прямой просьбы.

## Как это работает

1. Codex читает инструкции этого скилла и установленного Playwright-скилла.
2. PowerShell-адаптер запускает Playwright CLI из стабильной папки скилла и выбирает постоянную сессию `default`.
3. Сайт открывается в отдельном профиле Microsoft Edge в скрытом режиме.
4. Если требуется вход, Codex сообщает об этом и открывает видимое окно. Пользователь входит самостоятельно и пишет, что закончил.
5. Codex проверяет вход, закрывает видимое окно и продолжает в фоне с тем же профилем.
6. Перед отправкой скриншота Codex проверяет существование файла, PNG-сигнатуру, размер файла и размеры изображения.

Личный профиль Edge или Chrome не используется. Вход из встроенного браузера Codex автоматически не переносится. Скилл не является расширением браузера или самостоятельной программой: его запускает агент Codex.

## Требования

- Windows и установленный Microsoft Edge.
- Node.js 18+ и npm, включая `npx`.
- Codex с возможностью запускать локальные команды.
- Установленный официальный [Playwright-скилл OpenAI](https://github.com/openai/skills/tree/main/skills/.curated/playwright).

Текущий адаптер предназначен для Windows. Поддержка Linux и macOS в этом проекте не реализована.

## Что скачивается дополнительно

Скилл использует npm-пакет **[`@playwright/cli`](https://www.npmjs.com/package/@playwright/cli)** — CLI для управления браузером через Playwright. Исходный код и документация: **[microsoft/playwright-cli](https://github.com/microsoft/playwright-cli)**. Сам Playwright: [microsoft/playwright](https://github.com/microsoft/playwright).

Адаптер сначала ищет установленный `playwright-cli`, затем пакет в локальном npm-кэше. Если пакет не найден, запускает:

```powershell
npx --yes --package @playwright/cli playwright-cli
```

При первом запуске `npx` скачивает пакет и его зависимости из npm. Они не включены в этот репозиторий. Для скачивания нужен доступ к сети; версия при таком запуске не зафиксирована. В штатном workflow используется уже установленный Edge, отдельная установка Chromium этим скиллом не выполняется.

Официальный Playwright-скилл содержит инструкции для агента и устанавливается отдельно; наш адаптер не скачивает его автоматически.

## Установка

1. Установите официальный [Playwright-скилл](https://github.com/openai/skills/tree/main/skills/.curated/playwright) через установщик скиллов Codex. Например, попросите Codex: «Установи Playwright-скилл из openai/skills».
2. Скачайте этот репозиторий через **Code → Download ZIP** и распакуйте его.
3. Скопируйте содержимое репозитория в папку `browser-screenshot` внутри каталога скиллов Codex: `$CODEX_HOME/skills`, либо `~/.codex/skills`, если `CODEX_HOME` не задан. Внутри `browser-screenshot` должен лежать `SKILL.md`, без дополнительного уровня папок.
4. Начните новую сессию Codex, чтобы скилл появился в списке.

## Примеры запросов

```text
$browser-screenshot открой https://example.com и сделай скриншот
Открой X, найди пост про ИИ и сделай его скриншот
Сними всю страницу по этой ссылке
Открой сервис; если нужен вход, покажи окно для авторизации
```

## Качество изображения

Скриншот сохраняется как PNG без JPEG-перекодирования. PNG не добавляет потери при сжатии, но детализация зависит от viewport, плотности пикселей и исходного содержимого страницы. Нечёткая картинка внутри сайта не становится чётче от сохранения в PNG. Чат может уменьшать превью; для оценки качества открывайте оригинал в масштабе 100%.

## Локальные данные и ограничения

- Профиль, cookies и состояние входа хранятся локально и не входят в поставку скилла.
- Скриншоты остаются в `outputs/`; автоматического удаления нет.
- Снимки структуры страницы, журналы и другие runtime-файлы могут содержать сведения с сайтов. Не добавляйте их в репозиторий; `.gitignore` не удаляет уже отслеживаемые файлы.
- Пароли и коды вводит пользователь. Cookies из других профилей не копируются.
- Если сайт блокирует автоматизированный браузер или требует дополнительной проверки, скилл сообщает об ограничении и останавливается. Обход блокировок не реализован.
- Страница ошибки, незавершённая загрузка или окно входа не должны выдаваться за снимок запрошенного материала.
- Скилл работает по запросу; периодический мониторинг не настроен.
